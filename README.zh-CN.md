### 使用方法

1. 安装本挂件
2. 在文档编辑器中呼出斜杠菜单，点击「挂件」选项，选择本挂件插入挂件块
3. 在挂件块中选择需要汇总的行级元素类型，并选择是否包含嵌入块中的元素，即可生成汇总列表
4. 还可以点击挂件块中的刷新按钮，刷新汇总列表

### 汇总行级元素

挂件下拉框支持汇总以下 14 种行级元素（每次仅选择一种类型）：

标记、粗体、标签、斜体、下划线、删除线、备注、超链接、块引用、行级代码、行级公式、上标、下标、键盘。

### 展示效果

本挂件会根据当前运行场景自动适配展示效果；汇总类型、是否包含嵌入块等设置在各场景下保持一致：

#### 所见即所得编辑器

- 挂件以 iframe 形式嵌入文档，顶部显示控制面板（行级元素类型、是否包含嵌入块、刷新按钮）
- 自动汇总当前文档中符合条件的行级元素，在 iframe 内显示无序列表
- 列表项可点击，跳转到对应块
- 修改下拉选项或点击刷新按钮会重新解析并更新列表；选项会保存到挂件块属性，导出时沿用
- 同步编辑器主题样式，适配明亮/暗黑模式
- 无查询结果时显示「无查询结果」；解析较大文档时可能短暂显示「正在解析文档，请稍候...」

#### 编辑器导出预览

- 将挂件 iframe 块替换为 typography 无序列表，最终预览页中不再出现 iframe
- 列表项为纯文本，无跳转链接
- 无查询结果时移除挂件块

#### 导出图片

- 隐藏控制面板与 iframe 边框
- 将挂件 iframe 块替换为 protyle 无序列表块，最终输出中不再出现 iframe
- 列表项为纯文本，无跳转链接
- 无查询结果时移除挂件块

#### 导出 PDF

- 与导出图片相同，将挂件块替换为无序列表块
- 列表项末尾可能显示 `*` 锚点链接，可跳转到文档中对应块（目标块须存在于导出预览页；嵌入块内的元素因块 ID 为临时生成，无法建立链接）
- 无查询结果时移除挂件块

### 从「行内元素抓取」挂件迁移

1. 打开全局搜索，切换到 SQL 搜索方式，搜索：
  `SELECT * FROM blocks WHERE markdown LIKE '<iframe src="/widgets/widget-inline-extractor%';`
2. 搜索结果会显示工作空间中的所有「行内元素抓取」挂件块
3. 手动一个个插入本挂件，然后删除「行内元素抓取」挂件块
